# Contributing to HomeLab Stack

Thank you for your interest in contributing to HomeLab Stack!

## How to Contribute

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/homelab-stack.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Test your changes
6. Submit a Pull Request

## Development Setup

See README.md for setup instructions.

## Docker Services

This project uses Docker Compose to manage multiple services:
- Traefik (reverse proxy)
- Authentik (SSO)
- Prometheus/Grafana (monitoring)
- And many more...

## Code Style

- Follow Docker best practices
- Use environment variables for configuration
- Add labels for Traefik
