# Home Automation Stack — Home Assistant + Node-RED + Zigbee2MQTT
Smart home control, automation, and Zigbee device integration.
## Deployment
- Adjust Zigbee device path (`/dev/ttyACM0`) in docker-compose.yml.
- Start: `docker compose up -d`
- Access Home Assistant at http://localhost:8123, Node-RED at http://localhost:1880.
