# Media Stack

Jellyfin + Sonarr + Radarr + Prowlarr + qBittorrent + Jellyseerr

## Services

| Service | Port | Description |
|---------|------|-------------|
| Jellyfin | 8096 | Media server — stream movies & TV shows |
| Sonarr | 8989 | TV series management & automation |
| Radarr | 7878 | Movie management & automation |
| Prowlarr | 9696 | Indexer manager for Sonarr/Radarr |
| qBittorrent | 8080 | BitTorrent download client |
| Jellyseerr | 5055 | Media request & discovery portal |
