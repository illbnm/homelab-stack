# 🏠 Home Automation Stack

Complete smart home automation stack with Zigbee device support and visual flow orchestration.

## Services

| Service | Port | Description |
|---------|------|-------------|
| Home Assistant | `8123` | Smart home hub and automation engine |
| Node-RED | `1880` | Visual flow editor for automations |
| Mosquitto | `1883` / `9001` | MQTT broker (MQTT + WebSockets) |
| Zigbee2MQTT | `8080` | Zigbee device gateway |
| ESPHome | `6052` | ESP device firmware management |
