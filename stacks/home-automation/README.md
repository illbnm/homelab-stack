# 🏠 Home Automation Stack (Home Assistant, Node-RED, Mosquitto, Zigbee2MQTT, ESPHome)

> Enterprise-grade open-source smart home hub with Zigbee device coordination and automation pipelines.

## 📦 Services
- **Home Assistant (`2024.9.3`):** Network mode `host` configured for SSDP/UPnP/mDNS discovery.
- **Node-RED (`4.0.3`):** Visual event-driven workflow automation.
- **Mosquitto (`2.0.19`):** Secure MQTT message broker.
- **Zigbee2MQTT (`1.40.2`):** Universal Zigbee bridge.
- **ESPHome (`2024.9.3`):** Custom sensor/switch firmware manager.
