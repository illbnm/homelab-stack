# Robustness & Network Adaptation Suite

> **Bounty:** [illbnm/homelab-stack#8](https://github.com/illbnm/homelab-stack/issues/8) — $250 USD

## Included Utilities
- `scripts/setup-cn-mirrors.sh`: Automated Docker mirror configuration.
- `scripts/localize-images.sh`: CLI switcher for domestic mirror registries (`--cn`, `--restore`, `--check`).
- `scripts/check-connectivity.sh`: Diagnostic network latency probes.
- `scripts/wait-healthy.sh`: Polling container readiness wait with log dumps on timeout.
- `scripts/diagnose.sh`: System state collector.
- `config/cn-mirrors.yml`: Up-to-date registry translation mapping.
