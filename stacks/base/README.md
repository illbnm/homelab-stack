# 🌐 Base Infrastructure (Traefik, Portainer, Watchtower)

> Core edge routing, automated SSL termination, container orchestration, and automated updates.

## 📦 Services
- **Traefik (`v3.1.4`):** Dynamic reverse proxy, automatic Let's Encrypt SSL certificates.
- **Portainer (`2.21.3-alpine`):** Web GUI container manager.
- **Watchtower (`1.7.1`):** Nightly rolling image updater with ntfy push notifications.
