# Productivity Stack — Gitea + Vaultwarden + Outline
Self-hosted Git, password manager, and wiki.
## Deployment
- Change all `change-me` secrets in docker-compose.yml.
- Start: `docker compose up -d`
- Access Gitea at http://localhost:3000, Vaultwarden at http://localhost:8080, Outline at http://localhost:8000.
